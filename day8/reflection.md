# Day 8 Reflection

## 1. The Most Difficult Concept

The most difficult concept in this course was understanding how to design a system that handles many users at the same time without losing data or creating conflicts. Concepts such as database transactions, caching, load balancing, and scalability were initially challenging because they involve several components working together. I overcame this by breaking the design into smaller sections, studying what each component does, and applying the concepts to practical examples. Designing TicketHub helped me understand why a database transaction and appropriate constraints are essential when two customers try to buy the same seat.

## 2. Improving My Capstone

Based on the feedback and lessons from my capstone, NyumbaConnect, I would improve the booking and viewing functionality. I would make property availability updates more reliable, prevent duplicate bookings, and improve validation and error messages. I would also strengthen testing and security, especially around authentication and user permissions. These improvements would make the system more trustworthy and easier for tenants and landlords to use.

## 3. What I Will Learn Next

Next, I plan to strengthen my JavaScript skills and learn backend development with Node.js and Express. I want to understand REST APIs, database transactions, authentication, and automated testing through practical projects. I will also continue learning Git and GitHub so I can manage changes confidently and build a stronger software development portfolio.

## Conclusion

This course has helped me see that software development involves more than writing code. Good systems also require careful planning, reliable data handling, security, and thoughtful decisions about performance and user experience.
